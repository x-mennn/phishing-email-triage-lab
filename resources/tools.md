# Investigation Resources

Reference tools and services relevant to phishing email investigation and SOC analysis.

These resources are provided as analyst references and were not necessarily used in every investigation case.

- **VirusTotal** - Reputation and contextual analysis for URLs, domains, IP addresses, and file hashes.
- **URLScan** - URL and web-page analysis for investigating suspicious links and domains.
- **RDAP / WHOIS** - Domain registration and ownership information.
- **DNS Lookup** - DNS record and domain infrastructure investigation.
- **CyberChef** - Encoding, decoding, transformation, and data analysis.
